# CLAUDE.md

Заметки для будущих сессий Claude Code в этом репозитории.

## Что это

Интерактивная рабочая тетрадь по математике для 6 класса немецкой школы.
Ученица: родной русский, немецкий на уровне A1–A2.

Источник — **Parallelo Mathematik 6, Nordrhein-Westfalen** (Cornelsen):
учебник (Schülerbuch) и рабочая тетрадь (Arbeitsheft) с решебником.
Разбор всех отснятых страниц — в `material/INDEX.md`, туда же стоит заглянуть
перед тем, как делать новую тему.

Тетрадью пользуется ребёнок, чаще всего одна, без взрослого рядом. Отсюда два
следствия для любой правки: тупик без объяснения недопустим, а сломанная
страница означает сорванное занятие.

## Правило двух языков

Это главное архитектурное решение, от него зависит почти всё остальное.

- **Условие задания — по-немецки**, близко к формулировке учебника. На
  контрольной будет ровно этот текст, и знакомая фраза не должна выглядеть новой.
- **Перевод условия — по-русски, спрятан за кнопкой «Перевод».** Не потому что
  жалко: если перевод висит рядом, глаз читает только его. Одно нажатие — и он
  на экране, застрять невозможно.
- **Подсказки, разборы, объяснения — только по-русски.** Ученица здесь уже
  застряла; добавлять к математической трудности языковую незачем.
- Немецкие термины в русских объяснениях оставляем в скобках: «сократить (kürzen)».

Тип `Bilingual` требует обе строки — русский перевод формулировки не
опционален. Если правка позволяет оставить `ru` пустым, правка неверная.

## Стек

Vite 6 + React 19 + TypeScript + Tailwind 4 + KaTeX, zod для схемы контента,
vitest для тестов, react-router с **HashRouter**.

Плюс `vite-plugin-pwa`: тетрадь ставится на главный экран планшета как
приложение. Иконки рисует `scripts/make-icons.mjs` — не бинарники в репозитории,
а код, который можно поправить одной строкой (`npm run icons`).

Два решения, которые стоит сохранить:

- **HashRouter, а не BrowserRouter.** Адреса вида `#/lesson/...` не требуют
  от хостинга правил перезаписи — сайт работает на любом статическом хостинге
  без настройки.
- **`base: '/'`.** Было `'./'`, чтобы открывать `dist/` с диска, но у service
  worker область действия должна быть корнем. Раз занимаются с планшета через
  хостинг, выбран корень; открыть сборку двойным кликом с диска теперь нельзя,
  для локального просмотра есть `npm run preview`.

## Как устроен урок

Порядок повторяет учебник, но с одной добавкой в начале:

1. **Sprache** — фразы из формулировок темы (`lesson.phrases`) и два-три
   задания с `focus: 'sprache'`. Это добавка: в учебнике её нет, но именно
   здесь чаще всего ломается занятие.
2. **Слова урока** — термины из глоссария (`lesson.terms`).
3. **Erklärung** — теория: Merke и Beispiele из учебника.
4. **Aufgaben** — задания, отфильтрованные по выбранному уровню
   (`basis` / `mittel` / `plus`, значки ▽ ▷ ⋈ как в тетради).

Уровень запоминается в настройках. Если на выбранном уровне заданий нет,
страница показывает первый непустой: пустой экран читается как поломка.

## Структура

```
src/content/    учебный материал — то, что меняется чаще всего
  schema.ts     схема урока (zod). Расширять здесь, если нужен новый тип блока
  glossary.ts   немецко-русский словарь
  chapters/     одна глава — один файл
  index.ts      реестр глав; подключение новой главы — одна строка
src/lib/        проверка ответов, прогресс в localStorage
src/components/ карточка задания, формула, блоки теории, словарные плашки
src/pages/      оглавление, урок, словарь
material/       фотокопии учебника — вне git
```

## Правила, которые легко нарушить по невнимательности

**Не менять `id` урока или задания после того, как по ним занимались.**
К `id` привязан сохранённый прогресс (`localStorage`, ключ
`${lessonId}:${exerciseId}`). Переименование = обнуление прогресса, без
предупреждения.

**Не коммитить содержимое `material/`.** Немецкий учебник защищён авторским
правом. В репозиторий попадает переработанный урок — своя формулировка, свой
перевод, свои объяснения, — но не скан.

**У каждого задания должны быть `hints` или `solution`.** Это проверяет тест,
и это не формальность: ученица занимается одна. Исключение — `open`,
где роль разбора играет `reference`.

**Задания `open` не проверяются автоматически, и это намеренно.** `Begründe`
и `Beschreibe dein Vorgehen` нельзя сравнить со строкой, но выбрасывать их
нельзя: именно на них тренируется язык объяснения. Ученица пишет своими
словами, открывает образец и сама отмечает, сошлось ли. Тип
`AutoCheckedExercise` следит, чтобы `checkAnswer` не вызвали для них по ошибке.

**Проверка ответа должна прощать форму записи.** `3,5` и `3.5`, `20 cm` и `20`,
`Der Nenner.` и `nenner` — это один и тот же ответ. Ошибка формата, показанная
как математическая ошибка, заставляет ребёнка исправлять верное решение.
Вся эта логика — в `src/lib/check-answer.ts`, там же тесты на каждый случай.

## Проверки

```bash
npm test      # проверка ответов + целостность контента
npm run build # проверка типов и сборка
npm run lint
```

`src/content/content.test.ts` ловит то, что не ломает сборку, но ломает
занятие: повторяющийся id, ссылку на несуществующий термин глоссария, вариант
ответа с индексом за границей списка, задание без единой подсказки. Добавляя
новый вид контента, стоит добавить и проверку сюда.

## Планшет

Занимаются с планшета Android, а не с компьютера. Отсюда требования, которые
легко нарушить, правя вёрстку на большом экране:

- кнопки и варианты ответа должны оставаться крупными — палец не курсор;
- ничего, что требует наведения мыши: перевод и подсказки открываются нажатием;
- набор текста на экранной клавиатуре неудобен, поэтому длинные ответы бывают
  только в заданиях `open`, где текст всё равно проверяет сама ученица.

## Известные ограничения

Собранный бандл около 590 kB — почти всё это KaTeX со шрифтами. Для тетради,
которая открывается локально, это несущественно; при желании лечится
динамическим импортом.

Планы и нерешённые вопросы — [docs/ROADMAP.md](docs/ROADMAP.md).
