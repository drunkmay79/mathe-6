# Исходные материалы

Сюда кладём фотокопии страниц немецкого учебника и рабочей тетради.

Формат имени файла: `<источник>-s<страница>.jpg`

- `lb-s042.jpg` — Lehrbuch (учебник), страница 42
- `ah-s017.jpg` — Arbeitsheft (рабочая тетрадь), страница 17

Папка исключена из git (`.gitignore`): сканы защищены авторским правом и
остаются только на локальной машине. В репозиторий попадает не скан, а
переработанный урок в `src/content/chapters/`.

Как из скана получается урок — см. [docs/CONTENT_GUIDE.md](../docs/CONTENT_GUIDE.md).
