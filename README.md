# Mathe 6 — интерактивная рабочая тетрадь

Учебник, тетрадь и репетитор в одном месте: математика 6 класса по немецкому
учебнику, для ученицы с родным русским и немецким на уровне A1–A2.

Идея простая. Условие задачи ученица читает **по-немецки** — ровно так, как оно
напечатано в учебнике, потому что на контрольной будет именно этот текст.
Всё остальное — объяснения, подсказки, разбор ошибок — **по-русски**, на языке,
на котором она думает о математике. Перевод условия спрятан за кнопкой: он
всегда в одном нажатии, но не мозолит глаза, иначе немецкий не запоминается.

## Что уже работает

Источник — **Parallelo Mathematik 6, Nordrhein-Westfalen** (Cornelsen):
учебник и рабочая тетрадь. Первая глава «Teilbarkeit und Brüche» сделана
целиком: **7 тем, 131 задание, 21 интерактивный тренажёр**.

- **Интерактивные тренажёры в теории** — по три на тему. Это не задания:
  тут нечего сдавать, зато правило можно покрутить руками. Прыгун по числовой
  прямой, строитель прямоугольников из квадратиков, лампочки делимости,
  машина для суммы цифр, лупа на числовой прямой и другие.
- **Рисунки перед правилами.** Ребёнку, который отстал, картинка объясняет
  быстрее определения, поэтому рисунок идёт до правила, а не вместо него.
- **Язык задания отдельным блоком** перед теорией: фразы, которыми написаны
  задания темы, плюс задания на понимание формулировки. На уровне A1–A2
  задание чаще проваливается на глаголе-команде, чем на математике.
- **Три уровня сложности** ▽ ▷ ⋈ — те же, что в рабочей тетради.
- **Одиннадцать типов заданий**: число, дробь, множество чисел, выбор варианта,
  выбор нескольких, таблица wahr/falsch, соединение линиями, закрашивание доли,
  отметка на числовой прямой, короткий текст и свободное обоснование с образцом.
- Снисходительная проверка ответов: `3,5` и `3.5`, `20 cm` и `20`,
  `Der Nenner.` и `nenner` — всё это засчитывается. Ошибка формата не должна
  выглядеть как ошибка в математике.
- Проверка различает оттенки: несокращённая дробь — это «почти», неполное
  множество — «верно, но найдено не всё», а не ошибка.
- Ответы к заданиям тетради сверены с официальным решебником издательства.
- Немецко-русский словарь на 90 слов с подсказками, от какого слова термин
  образован: Teiler от teilen, Zähler от zählen.
- Прогресс в localStorage: без аккаунтов, без сервера, работает офлайн.

## Как это попадает на планшет

Занимаются с планшета, поэтому тетрадь собрана как **PWA**: сайт выкладывается
на статический хостинг, на планшете открывается ссылка и нажимается «Добавить
на главный экран». Дальше это выглядит и ведёт себя как приложение — своя
иконка, запуск на весь экран без адресной строки, работа без интернета
(при сборке в кеш попадают все файлы, включая шрифты формул).

Ничего публиковать в Google Play или App Store не нужно.

```bash
npm run build     # готовый сайт складывается в dist/
```

```bash
npm run deploy    # собрать и выложить на GitHub Pages
```

Публикация идёт в ветку `gh-pages`. Автосборка через GitHub Actions была бы
удобнее, но токен `gh` на этой машине не имеет права `workflow`; если понадобится,
это чинится одной командой `gh auth refresh -s workflow`.

Содержимое `dist/` заливается на любой статический хостинг. Роутер работает
через хеш (`#/lesson/...`), поэтому правила перезаписи адресов хостингу
не нужны. `base` при этом `/` — значит открыть `dist/index.html` двойным
кликом с диска не получится, нужен хостинг или `npm run preview`.

## Как устроен проект

```
src/
  content/          учебный материал — то, что чаще всего меняется
    schema.ts       схема урока: что вообще можно описать
    glossary.ts     немецко-русский словарь
    chapters/       главы; один файл — одна глава
    index.ts        реестр: подключение главы к приложению
  lib/
    check-answer.ts проверка ответов
    progress.ts     прогресс в localStorage
  components/       карточка задания, формула, блоки теории, словарные плашки
  pages/            оглавление, урок, словарь
material/           фотокопии учебника — локально, вне git
docs/               как переводить страницы учебника в уроки
```

## Как добавить материал

Коротко: положить скан в `material/`, создать или дополнить файл главы
в `src/content/chapters/`, подключить главу в `src/content/index.ts`,
прогнать `npm test`.

Подробно, с разбором каждого типа задания —
[docs/CONTENT_GUIDE.md](docs/CONTENT_GUIDE.md).

## Про сканы учебника

Папка `material/` не попадает в git. Немецкий учебник и рабочая тетрадь защищены
авторским правом; сканы остаются на локальной машине. В репозиторий попадает не
скан, а переработанный урок: своя формулировка, свой перевод, свои объяснения.
