# Как превратить страницу учебника в урок

Пошагово: от фотографии страницы до работающего урока в тетради.

## 0. Куда положить скан

`material/lb-s042.jpg` — Lehrbuch (учебник), страница 42
`material/ah-s017.jpg` — Arbeitsheft (рабочая тетрадь), страница 17

Папка `material/` вне git — см. [material/README.md](../material/README.md).

## 1. Один урок — одна тема, а не одна страница

Разворот учебника обычно содержит одну тему, но иногда две. Урок делается по
теме, а не по номеру страницы. Хороший размер: 3–6 заданий. Больше — ученица
устаёт и бросает на середине, а прогресс показывает «почти ничего не сделано».

## 2. Заполнить каркас урока

Открыть файл нужной главы в `src/content/chapters/`, добавить объект урока.
Образец со всеми типами блоков и заданий — `01-brueche.ts`.

```ts
{
  id: 'kuerzen-und-erweitern',      // латиницей, через дефис; это и адрес страницы, и ключ прогресса
  title: { de: 'Kürzen und Erweitern', ru: 'Сокращение и расширение дробей' },
  summary: 'Чему учит урок — одно-два предложения по-русски.',
  terms: ['kuerzen', 'erweitern'],  // id из glossary.ts, проверяются тестом
  source: { book: 'lb', page: 18 }, // откуда взято
  theory: [ /* … */ ],
  exercises: [ /* … */ ],
}
```

**id урока нельзя менять после того, как по уроку позанимались**: к нему привязан
сохранённый прогресс. Переименование = урок начинается с нуля.

## 3. Правило двух языков

| Что                           | Язык     | Почему                                                 |
| ----------------------------- | -------- | ------------------------------------------------------ |
| Условие задания (`prompt.de`) | немецкий | На контрольной будет ровно этот текст                  |
| Перевод условия (`prompt.ru`) | русский  | Спрятан за кнопкой, всегда в одном нажатии             |
| Подсказки (`hints`)           | русский  | Ученица тут уже застряла — добавлять сложности незачем |
| Разбор (`solution`)           | русский  | Понять надо математику, а не немецкий                  |
| Шаги примера (`explain`)      | русский  | То же самое                                            |

`prompt.de` стоит брать близко к формулировке учебника: цель — чтобы знакомая
фраза на контрольной не выглядела новой. Немецкие термины в русских
объяснениях полезно оставлять в скобках: «сократить (kürzen)».

## 4. Блоки теории

- `text` — обычный абзац, двуязычный.
- `math` — формула отдельной строкой, KaTeX, с необязательной подписью.
- `rule` — правило в жёлтой рамке. То, что нужно выучить наизусть. Не больше
  одного-двух на урок, иначе рамки перестают выделяться.
- `example` — разобранный пример: условие плюс шаги. Каждый шаг — формула
  и объяснение, что именно произошло.
- `visual` — рисунок с подписью. `art` — id из `src/components/illustrations`,
  `caption` — по-русски, что на картинке происходит.

Про рисунки отдельно. Ребёнок, отставший по программе, разбирается в картинке
быстрее, чем в определении, поэтому картинка идёт **до** правила, а правило
после неё читается уже как подпись к понятному. Правило отбора простое: если
рисунок можно убрать и ничего не потеряется, он лишний. Рисуются они кодом
в `illustrations/index.tsx` — остаются чёткими на любом экране и правятся
одной строкой. Тест проверяет, что рисунок с таким `art` существует.

Формулы пишутся синтаксисом KaTeX, обратный слэш в строке TypeScript
удваивается: `'\\frac{3}{4}'`.

## 5. Типы заданий

У каждого задания есть `level` (`basis` / `mittel` / `plus` — три уровня
рабочей тетради, ▽ ▷ ⋈) и `focus`. По умолчанию `level: 'basis'` и
`focus: 'mathe'`. Задания с `focus: 'sprache'` показываются в разминке
до теории, а не в общем списке.

**`number`** — числовой ответ.

```ts
{ kind: 'number', answer: 0.75, tolerance: 0.01, unit: { de: 'cm', ru: 'см' } }
```

`answer` пишется через точку (это JavaScript), ученице показывается через
запятую. `tolerance` нужен там, где в ответе округление; без него сравнение
точное. Единица измерения необязательна: `20 cm` засчитывается и без неё.

**`fraction`** — обыкновенная дробь.

```ts
{ kind: 'fraction', numerator: 3, denominator: 4, requireReduced: true }
```

`requireReduced: true` — когда в задании стоит «Kürze» и сокращение и есть суть
задания: `6/8` тогда получит ответ «значение верное, но можно сократить».
`false` — когда важно только значение, например при расширении дроби.

**`set`** — множество чисел: Teiler-Menge, Vielfachen-Menge.

```ts
{ kind: 'set', label: 'T_{32} =', values: [1, 2, 4, 8, 16, 32] }
```

Порядок и повторы не важны. Проверка различает три случая: назвала не всё
(«всё верно, но не найдено ещё 2 числа» — это верный ход мысли, а не ошибка),
назвала лишнее (тогда неверно понято правило, и лишнее число называется прямо)
и полный ответ. `label` — подпись перед полем, строка KaTeX.

**`choice`** — выбор варианта. `correct` — индекс с нуля.

**`truefalse`** — таблица утверждений, как «Sind die Aussagen richtig?».

```ts
{
  kind: 'truefalse',
  statements: [
    { de: '5 ist ein Teiler von 25.', ru: '5 — делитель 25.', correct: true,
      why: '25 : 5 = 5, без остатка.' },
  ],
}
```

`why` показывается после проверки — по строке на утверждение. Без него
таблица превращается в угадайку.

**`match`** — соединить линиями: «Verbinde die Zahl mit ihren Vielfachen».

```ts
{
  kind: 'match',
  left: [{ id: 'l8', label: '8' }],
  right: [{ id: 'r24', label: '24' }, { id: 'r36', label: '36' }],
  pairs: [['l8', 'r24']],
}
```

У одного элемента слева может быть несколько связей. Тест проверяет, что все
`pairs` ссылаются на существующие `left` и `right`.

**`text`** — короткий текстовый ответ, обычно немецкий термин.
`accept` — все написания, которые считаем верными. Регистр, умляуты
(`kuerzen` = `kürzen`), артикль и точка в конце нормализуются, их
перечислять не нужно.

**`open`** — свободный ответ: `Begründe`, `Erkläre`, `Beschreibe dein Vorgehen`.

```ts
{
  kind: 'open',
  reference: 'Образец ответа по-русски.',
  referenceDe: 'Как это звучало бы по-немецки — если фразу стоит запомнить.',
}
```

Автоматически не проверяется: ученица пишет своими словами, открывает образец
и сама отмечает, сошлось ли. Выбрасывать такие задания нельзя — именно на них
тренируется язык объяснения, который спросят на уроке.

## 6. Подсказки и разбор

У каждого задания должны быть либо `hints`, либо `solution` — это проверяет
тест. Ученица занимается одна: тупик без объяснения означает конец занятия.
Исключение только для `open`: там роль разбора играет `reference`.

Хорошая цепочка подсказок ведёт к ответу, но не выдаёт его:

1. Куда посмотреть: «Сначала знаменатель: на сколько частей разделили целое?»
2. Что посчитать: «Наибольший общий делитель здесь — 4.»
3. Ответ целиком — это уже `solution`, не подсказка.

## 7. Язык задания

В уроке есть отдельное поле `phrases` — фразы, которыми написаны задания темы.
Они показываются до теории, потому что на уровне A1–A2 задание чаще
проваливается на глаголе-команде, чем на математике.

```ts
{
  de: 'Nenne die ersten fünf Vielfachen der Zahl.',
  ru: 'Назови первые пять кратных числа.',
  note: 'Nenne — просто назови. Расписывать решение не требуют.',
}
```

`note` нужен там, где похожие команды требуют разного: `Nenne` против
`Berechne`, `Begründe` против `Gib an`.

Туда же стоит добавить два-три задания с `focus: 'sprache'` — проверить, что
формулировка понята. Они попадают в ту же разминку.

## 8. Новые слова

Если в задании встретилось слово, которого нет в `src/content/glossary.ts`, —
добавить его туда и вписать id в `terms` урока. Тест падает, если урок
ссылается на несуществующий термин.

Для существительных указывать артикль и множественное число: в немецком их
приходится учить вместе со словом.

Поле `memo` — подсказка, от какого слова термин образован: Teiler от teilen,
Zähler от zählen, Quersumme от quer «поперёк». Немецкие математические слова
почти все прозрачные, и один раз увиденная связь держится в голове гораздо
лучше заученного перевода. Показывается в словарной плашке под переводом.

## 9. Новая глава

1. Создать `src/content/chapters/02-....ts` по образцу первой главы.
2. Импортировать её в `src/content/index.ts` и добавить в массив `CHAPTERS`.

Больше нигде ничего править не нужно: оглавление, маршруты и прогресс
строятся из этого списка.

## 10. Проверить

```bash
npm test
```

Тесты ловят то, что не ломает сборку, но ломает занятие: повторяющийся id,
ссылку на несуществующий термин, вариант ответа с индексом за границей списка,
связь на несуществующий элемент в `match`, повтор в `set`, урок без заданий
базового уровня и задание без единой подсказки.
